# .github

Plantillas de la organización GSSgroupIT. GitHub las muestra en todos los repositorios de la organización que no tienen su propia carpeta `.github/ISSUE_TEMPLATE`.

| Plantilla | Para qué |
|---|---|
| [Defecto encontrado en QA](.github/ISSUE_TEMPLATE/defecto-qa.yml) | Reportar un defecto hallado en QA y clasificar su origen. Pone las etiquetas `bug` y `qa`, que deben existir en el repositorio. |

Este repositorio es público porque GitHub solo toma las plantillas de la organización de un repositorio `.github` público. Aquí solo van plantillas.
